Example: 1

    <div className="hidden md:block">
        Hello
    div>

Read it like:

Mobile: hidden

Desktop: block

Mobile Screen = small  => hidden

Result: Nothing visible

Desktop Screen = large => block

Result: Visible on Desktop screen
